Algorithm Complexity Notes

Bubble Sort:
Best = O(n)
Average = O(n²)
Worst = O(n²)
Space = O(1)

Selection Sort:
Best = O(n²)
Average = O(n²)
Worst = O(n²)
Space = O(1)

Insertion Sort:
Best = O(n)
Average = O(n²)
Worst = O(n²)
Space = O(1)

Merge Sort:
Best = O(n log n)
Average = O(n log n)
Worst = O(n log n)
Space = O(n)

Quick Sort:
Best = O(n log n)
Average = O(n log n)
Worst = O(n²)
Space = O(log n) average

Note:
Quick Sort uses O(log n) auxiliary stack space on average, but in the worst case it can use O(n) extra space for very unbalanced partitions.
